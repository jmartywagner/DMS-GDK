DMS FURNACE -> DMR V0.3.1
=========================

Convertit un projet Furnace compatible avec le profil audio DMS-1 vers le format musical DMR.

Profil DMS-1 pris en charge :
- OPZ / YM2414 : canaux FM 1 a 4
- AY / SSG : canaux A, B et C
- YM2610 : donnees ADPCM-A et ADPCM-B

Lancement : `DMS_FURNACE_DMR.bat`.

Le convertisseur applique les limites de canaux DMS-1 et produit le contrat binaire DMR 0.1 utilise par le runtime.
