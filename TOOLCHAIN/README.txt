DMS-GDK - TOOLCHAIN MOTOROLA 68000
=================================

La toolchain croisee Motorola 68000 se telecharge separement afin de garder le depot GitHub leger.

Installation Windows :
    ADMIN\REPAIR_TOOLCHAIN_68000.bat

Destination locale :
    TOOLCHAIN\m68k-elf

Verification :
    ADMIN\DMS_DOCTOR.bat

Aucune modification permanente du PATH Windows est necessaire.
